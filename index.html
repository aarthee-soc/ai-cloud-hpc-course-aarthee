02 · Course objectives

What you will learn to do

By the end of the course, students should be able to connect technical concepts with measurable engineering decisions.

01 · Understand systems

Explain cloud service models, virtualisation, HPC architectures and AI workload characteristics.

02 · Build and deploy

Practise cloud deployment, containerisation, parallel programming and performance measurement.

03 · Analyse performance

Compare utilisation, scalability, latency, throughput, cost and energy consumption.

04 · Design intelligent solutions

Develop AI-assisted scheduling, autoscaling, fault-detection and resource-optimisation ideas.

05 · Evaluate responsibly

Consider fairness, security, privacy, sustainability and academic integrity.

06 · Communicate findings

Present evidence through reports, dashboards, demonstrations and reflective portfolios.

08 · Capstone direction

From experiment to evidence-backed solution

Build a small, reproducible cloud-HPC optimisation prototype and communicate what the measurements actually show.

Suggested project workflow

Define a workload and constraints → establish a baseline → implement a scheduling or monitoring approach → run repeatable experiments → compare results → discuss limitations and responsible-use considerations.

Evidence to present

Problem statement, architecture diagram, dataset or workload assumptions, code repository, experiment configuration, latency/throughput/utilisation results, cost or energy discussion, limitations and a short demonstration.
